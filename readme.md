# Лабораторная работа №5. Вариант 9: Музыкант и звукорежиссёр

## Структура HTML-разметки
*   **`<header>`** — содержит заголовок панели звукорежиссёра, имя автора и верхние интерактивные кнопки смены темы и скрытия плейлиста.
*   **`<main>`** — центральный блок управления, включающий:
    *   Панель действий с кнопками добавления новой дорожки и полной очистки треклиста.
    *   Контейнер плейлиста со списком треков.
*   **`<ul>` / `<li>`** — динамические списки для отображения структуры карточек музыкальных треков.
*   **`<footer>`** — нижняя часть страницы с информацией об авторских правах.

## Функционал JavaScript (DOM & LocalStorage)
*   **Поиск элементов**: Использование методов `getElementById`, `querySelector` и демонстрационного `querySelectorAll`.
*   **Добавление данных**: Создание всплывающих окон `prompt()` для ввода названия и длительности трека с обязательной валидацией на пустые пробелы через `.trim()`.
*   **Динамическая сборка DOM**: Создание элементов через `document.createElement`, наполнение их контентом и добавление с помощью `appendChild`.
*   **Интерактивные элементы**: Поддержка чекбоксов «Избранное» для изменения флага `isFavorite` внутри объектов массива и кнопок мгновенного поштучного удаления `.splice()`.
*   **Сброс плейлиста**: Функция полной очистки массива данных с предварительным подтверждением действия пользователя через `confirm()`.
*   **Переключение интерфейса**: Метод `classList.toggle('hidden')` для скрытия и отображения плейлиста, а также `classList.replace()` для смены темы на `<body>`.
*   **Синхронизация с веб-хранилищем**: Автоматическое сохранение структуры данных, текущей темы и видимости плейлиста в `localStorage`. Восстановление данных происходит сразу в момент срабатывания события `DOMContentLoaded`.
*   **Обработка потенциальных ошибок**: Жесткая проверка существования всех узлов DOM дерева на старте скрипта во избежание критических ошибок.

## Стилизация CSS
*   **CSS-переменные (`:root` и `body.dark-theme`)**: Используются для плавной, бесшовной смены цветовых схем в сине-фиолетовых тонах без перезагрузки страницы.
*   **Анимации и эффекты**: Свойства `transition` обеспечивают плавное изменение цвета фона, а при наведении на треки (`:hover`) срабатывает сдвиг по оси X (`transform: translateX`).
*   **Приоритетное скрытие**: Класс `.hidden` со свойством `display: none !important` гарантирует надежное скрытие блоков вне зависимости от их исходных стилей отображения.
